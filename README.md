## 📱 Sobre o projeto

O **CineFlix** é um aplicativo mobile desenvolvido com **React Native**, que simula uma plataforma de filmes, permitindo visualizar listas e detalhes de cada título.

Este projeto foi criado com foco educacional, explorando conceitos fundamentais do desenvolvimento mobile.

---

## ✨ Funcionalidades

✔️ Listagem de filmes  
✔️ Tela de detalhes  
✔️ Navegação entre páginas  
✔️ Interface simples e intuitiva  
✔️ Estrutura organizada em componentes
